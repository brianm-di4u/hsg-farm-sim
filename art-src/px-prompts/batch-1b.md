# Batch 1b: 1871 regenerations (palette)

These five came out in the reference image's cream-and-green Victorian palette. That belongs to 1886: in 1871 Valley
Street was raw board-and-batten, whitewash and false fronts (research/visual-eras.md §3, §8). Regenerate each with
the batch-1 description plus this palette rule:

> **Palette: weathered, unpainted grey-brown boards (#A58A64 family), whitewash (#EFE8DA) on some walls, dark
> weathered shingles, rust-red brick only for chimneys. No green trim, no cream-and-green paint, no Victorian
> gingerbread, no ornate railings.** Plain square posts, plain board railings, simple frontier carpentry.
