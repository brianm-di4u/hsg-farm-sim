# Clothing reference sources

One table per era. IDs (C<era>-<n>) are stable; cite them as "supports: C1886-3". File paths are relative to this folder. Every image is a downscaled JPG (1024 px or less on the long side) of the source file linked in the last column. Dates and places were checked on each source page; anything inferred is marked [inferred]. See ../README.md for the licence policy.
